# HelperProfiles 2.1.0.0

HelperProfiles 2.1.0.0 is the validated release of the twenty-worker A–T identity pool, per-save roster availability management and the new two-tab Helper Management interface.

## What’s new

- Expanded the permanent helper identity pool from A–J to A–T.
- Added stable `helper01`–`helper20` canonical identities.
- Added per-save ON/OFF roster management.
- Added the **Appearances** and **Helper Roster** tabs under one `RCTRL + ;` management interface.
- OFF-roster workers are excluded from cycling, the overlay, Selected/Next calculations and hiring.
- Added active-worker and minimum-roster protection.
- Added guarded **Disable Others** and **Enable All** actions.
- Preserved AvatarSwitcher bindings, HelperPayroll roles, compensation overrides and ledger identities when workers are disabled and restored.
- Kept HelperPayroll roles visible while the operational roster is filtered.
- Added automatic A–J/K–T overlay paging.
- Added `hpRoster` and `hpRosterManage` diagnostics and management commands.
- Added Hired Helper Tool and external-roster incompatibility protection.
- Resolved the FPS regression found during alpha testing.

## Helper Management

Press `RCTRL + ;` to open:

- **Appearances** — bind saved AvatarSwitcher appearances to helper slots.
- **Helper Roster** — choose which A–T workers are operationally available.

Staged changes survive tab switching. Closing without saving discards them.

## Roster safeguards

- Active workers cannot be switched OFF.
- At least one worker must remain ON roster.
- Save revalidates worker activity.
- Disable Others preserves the selected worker and every active worker.
- The game fallback cannot allocate an OFF-roster worker when all enabled workers are busy.

## Compatibility

HelperProfiles remains incompatible with **Hired Helper Tool** because both mods own the helper roster. HelperProfiles now detects the conflicting 30-worker roster and disables itself safely for that session.

AvatarSwitcher and HelperPayroll remain optional companion mods.

## Save data

Roster availability is stored per savegame at:

```text
modSettings/FS25_HelperProfiles/saves/savegameX/roster.xml
```

Existing saves without this file start with all twenty workers ON roster. Turning a worker OFF does not erase their appearance, payroll assignment or history.

## Validation

This release passed in-game testing for:

- A–T expansion and identity persistence;
- save/reload roster persistence;
- overlay, cycling, Selected/Next and hiring filtering;
- active-worker and last-worker safeguards;
- busy-roster fallback protection;
- appearance and payroll retention;
- tab switching, staged changes and independent saves;
- Hired Helper Tool incompatibility detection;
- stable FPS with the overlay and management interface open or closed.

## Installation

Download `FS25_HelperProfiles.zip` and place it directly in the Farming Simulator 25 mods folder. Do not unpack it.
