# HelperProfiles 2.1.2.0

HelperProfiles 2.1.2.0 is the ModHub-aligned maintenance and companion-integration release following the published 2.1.1.0 build.

## Changes

- Added live **HelperPayroll payroll-period cost** information to both the main HelperProfiles overlay and the Helper Roster.
- In HelperPayroll `dailyPayroll` mode, completed-but-unpaid work remains visible until payroll settlement instead of disappearing when a job finishes.
- Active and pending HelperPayroll work is combined by worker, game day and farm without double-applying call-out or minimum charges.
- Added support for HelperPayroll snapshot day segments so active jobs crossing midnight remain correctly projected.
- Updated the ModHub metadata to **descVersion 115**.
- Added the public GitHub project link to the ModHub description so the submitted version can be verified against the existing public release history.
- Added a direct HelperPayroll GitHub link to the ModHub description because the optional companion mod is not yet available on ModHub.
- Removed the default `A` menu binding that conflicted with the base-game MOVE LEFT assignment.
- Reduced routine HelperProfiles diagnostic output written to `log.txt` while preserving protected-call errors and compatibility warnings.
- Retains all fixes and Integration API v7 functionality from 2.1.1.0, including scoped preferred-worker hiring, AutoDrive worker continuity and the vehicle-input keybind fix.
- Rebalanced the Helper Roster table to accommodate the new Current Cost column.

## HelperPayroll integration

HelperPayroll remains optional. When a compatible HelperPayroll build exposing the payroll snapshot API is present, HelperProfiles displays each worker's read-only payroll role and accrued payroll-period cost. Payroll policy, rates, settlement and ledger accounting remain owned by HelperPayroll.

HelperProfiles does not calculate wages independently; it displays the authoritative payroll information supplied through the companion API.

## ModHub resubmission

This build preserves the project's existing public GitHub version lineage rather than resetting the mod to 1.0.0.0. The GitHub project URL is included directly in the ModHub description.

## Compatibility

- Single-player only.
- AvatarSwitcher remains optional.
- HelperPayroll remains optional.
- AutoDrive remains optional.
- Hired Helper Tool remains incompatible because it also owns the helper roster.
- Existing HelperProfiles 2.1.x save data and per-save roster/appearance files remain compatible.
- Alpha 6 / World Workers experimental code is not included.

## Installation

Download `FS25_HelperProfiles.zip` and place it directly in the Farming Simulator 25 mods folder. Do not unpack it.
